## 初始化執行步驟（使用者說「好」後依序執行）

> 先讀 `ai-os:env-setup` 第一、二節。

1. 填入所有常駐檔：`CLAUDE.md` 第一行的 `{專案名稱}`、STACK_RULES（含上方技術棧、目錄結構與產出物規範）、領域詞彙初始詞條；`此次任務.md` 的「專案階段」（照上方填入，並勾「開案」）與「目前核准的階段與功能」；`方案紀錄.md`（確認版技術棧表每一列與預先核准事項帶入速查表，脈絡區補選型原因）；最後把 `此次任務.md` 的「當前步驟」填入第一步（空的會在重開後被當成還沒開案）
2. `git init -b main`（已經有 `.git` 且有 commit ＝已開過案，不要重建，改成接續）
3. 依上方目錄結構建立專案（腳手架指令依 STACK_RULES，一律加 `--no-git`。工具拒絕非空資料夾時，在暫存資料夾建好再搬進來，不可覆寫 `.gitignore`、`CLAUDE.md`）
4. 依 STACK_RULES 追加需要的 MCP 到 `.mcp.json`
5. `codegraph init -i` 建立依賴索引
6. 補好測試與 CI 設定：`playwright.config.ts` 的 `webServer`（依 STACK_RULES 的開發指令與埠號）、`.github/workflows/test.yml` 需要的環境變數（用測試假值）
7. `git status` 確認 `.env*`／`_secrets/` 未被追蹤；先跑 STACK_RULES 的 build／型別檢查（`playwright.config.ts` 算程式碼，首次 commit 一定要有驗證紀錄），再照 `ai-os:env-setup` 的「應 commit」清單做首次 commit，訊息寫「建立專案骨架（AI OS）」
8. 有 GitHub 倉庫網址 → `git remote add origin <網址>`、`git push -u origin main`；打標籤 `git tag -a milestone-YYYYMMDD-init -m "開案完成"` 並 `git push --tags`
9. 請使用者重開 Claude Code（步驟見 `ai-os:start-project` 第 5 步）；`/mcp` 確認 codegraph 與追加的 MCP 都已載入後，才進入第一個功能
