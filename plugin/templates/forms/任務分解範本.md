# 任務分解範本

> 空白格式範本，不要直接填在這裡。填好的內容存到 `_管理/任務分解.md`。
> 何時用、怎麼做見 `ai-os:big-task` 技能。

```markdown
# 任務分解：{大任務名稱}

- 目標（一句話）：
- 完成標準（使用者能自己確認的）：
- 分支：`feat/{英文短名}`　起點 hash：（`git rev-parse HEAD` 的結果，最後審查要用）
- 建立日期：YYYY-MM-DD

## 切片清單

| # | 做完使用者能做什麼 | 要等哪片先完成 | 狀態 | 驗證結果 | Commit |
|---|---|---|---|---|---|
| 1 | （例：在列表頁按「新增」，填完送出後資料出現在列表上）| 無 | 待做 | | |
| 2 | | 1 | 待做 | | |

## 各片細節

### 1：{名稱}
- 會碰到：資料表／邏輯／畫面／測試（刪掉沒碰到的）
- 具體要做什麼：（寫清楚欄位、規則、錯誤時顯示什麼、會改哪些檔；不要寫「跟第 1 片類似」「加上驗證」這種要靠猜的話——如果派給子 Agent，它看不到這段對話）
- 驗收標準：
  - [ ]

## 最後的整體審查
- 日期：
- 結果：通過／有問題（列出並處理）
```

> 「做完使用者能做什麼」要寫使用者的行為，不是實作步驟。✅「使用者能編輯一筆訂單」 ❌「建立 update API 與表單元件」。
